LANTERN MARCH / 등불의 전선

1. Extract the entire ZIP into a folder.
2. Double-click PLAY_LANTERN_MARCH.bat.
3. Your browser opens the game. Keep the server window open; Enter stops it.

Requires Windows PowerShell5.1+ and Node.js20+ (https://nodejs.org). Node is installed on the current development PC. No Godot installation needed to play this Web package.
If port8060 is occupied, stop the old server before starting this copy.
Do not double-click index.html or use file://.

A/D or arrows: move;1–6:summon;J/K/L:skills;Escape:pause. Mouse and touch buttons supported. Protect your hero and destroy the enemy gate; stages5/10 require defeating the boss. Train/equip between stages.
Progress is saved per browser/site origin. Always use http://127.0.0.1:8060/ for the same local save. Browser site-data deletion removes progress.

Deploy: upload the complete build/web directory to static HTTPS hosting. Keep asset names intact. PWA metadata and a versioned service worker are included. No public hosting account required for local play. Native Android/iOS builds are deferred.
