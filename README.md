# Lantern March / 등불의 전선

Godot 4.6 stable 기반 단일 전선 전투 MVP. 영웅을 이동시키고 병력을 소환하며 오라·스킬로 적 기지를 돌파한다.

실행·조작·테스트: [README_FOR_REVIEW.md](README_FOR_REVIEW.md). 상세 감사 및 미완료 플랫폼: [PROJECT_AUDIT.md](PROJECT_AUDIT.md).

Godot에서 project.godot을 Import하고 F5로 실행. Web 빌드는 build/web에 있으며 Node.js로 node tools/serve.mjs build/web 8060 실행 후 localhost:8060에 접속한다.

원본 아트/음향은 자체 제작한 MVP 임시 자산이다. Android/iOS native 빌드는 포함되지 않는다.
